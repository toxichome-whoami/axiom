## Quick Update Commands

To update your skills or install new ones, use the following `npx` commands directly in your terminal:

### 1. Update All Skills to the Latest Versions
```bash
# Pulls latest revisions of all 2,687+ installed skills into ~/.agent/skills
npx agentic-awesome-skills --antigravity --all
```

### 2. Check for Updates First (Dry Run)
```bash
# Previews which skills have upstream changes without writing to disk
npx agentic-awesome-skills --antigravity --all --dry-run
```

### 3. Audit Local Skills Health
```bash
# Scans installed skills for missing files, invalid frontmatter, or broken links
npx agentic-awesome-skills audit
```

### 4. Install / Update Individual Skills via Skills CLI
```bash
# Search registry for a specific skill
npx skills search <skill-name>

# Add or update a specific skill
npx skills add <skill-name>

# Update all individually tracked skills
npx skills update
```
